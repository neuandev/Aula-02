# Aula 01 + Atividades da Aula 02

Projeto de página de perfil com HTML, CSS e JavaScript, complementado com um primeiro projeto Node.js.

## Atividades da Aula 02

- `script.js` vinculado ao HTML com `defer`.
- `console.log("Funcionou!")` para testar o carregamento do JavaScript.
- Alteração do `h1` usando `textContent`.
- Botão de alternância entre tema claro e escuro com `querySelector`, `addEventListener` e `classList.toggle("modo-escuro")`.
- Efeito `mouseover`/`mouseout` na foto com `scale(1.1)`.
- Relógio em tempo real atualizado a cada segundo com `setInterval()`.
- Projeto Node.js com `npm init -y`, `index.js` e pacote `chalk`.

## Executar a página

Abra o projeto no VS Code e use a extensão **Live Server** para visualizar o HTML.

## Executar o Node.js

No terminal, dentro desta pasta:

```bash
npm install
npm start
```

O terminal exibirá as mensagens coloridas usando o pacote `chalk`.
